Siga as instruções abaixo para configurar e criar backgrounds personalizados para o seu sistema muOS.

## Configurações Importantes

* **Caminho da pasta:** `/SD1 (mmc)/MUOS/info/catalogue/*nome do console*`

* **Configuração do muOS:** Configure a Artbox para **Fullscreen + Behind**. Isto garante que a lista de jogos apareça corretamente sobre o fundo.

## Passo a Passo

### 1. Escolha o estilo do seu background

Navegue pelas abas do menu no site (Editor, Art Book Next, Gradiente, etc.) para selecionar o template que deseja utilizar.

![Seleção de Estilo](https://fabziano.github.io/backgroundMuOS/assets/img/tutorial/tutorial1.png)

### 2. Como obter a imagem

Pode utilizar imagens da internet ou do seu computador.

* **Internet:** Clique com o botão direito na imagem desejada e selecione "Copiar imagem".

* **Computador:** Abra a imagem num visualizador, clique com o botão direito e selecione a opção de copiar.

*Nota: A resolução da imagem original influencia diretamente na qualidade do resultado final.*

![Obtendo Imagem](https://fabziano.github.io/backgroundMuOS/assets/img/tutorial/tutorial2.png)

### 3. Colando a imagem no editor

Retorne ao site e utilize o botão de colar dentro do template selecionado. É recomendável escolher uma imagem para o background geral e outra específica para a capa (boxart) do jogo.

![Colando Imagem](https://fabziano.github.io/backgroundMuOS/assets/img/tutorial/tutorial3.png)

### 4. Salvando o arquivo

Para que o muOS reconheça a imagem automaticamente:

1. Renomeie o arquivo com o **mesmo nome exato da ROM** do seu jogo.

2. Clique em baixar para gerar o arquivo `.png`.

3. Transfira o arquivo para a pasta correspondente no cartão SD.

![Salvando Imagem](https://fabziano.github.io/backgroundMuOS/assets/img/tutorial/tutorial4.png)
